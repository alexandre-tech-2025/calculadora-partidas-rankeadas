# 🏆 Calculadora de Partidas Rankeadas - DIO

Projeto desenvolvido para o desafio da DIO com foco em lógica de programação utilizando JavaScript.

## 📌 Objetivo
Criar uma função que calcula o saldo de vitórias e determina o nível do jogador com base no número de vitórias.

## 🧠 Conceitos Utilizados
- Variáveis
- Operadores
- Laços de repetição
- Estruturas de decisão
- Funções

## 📊 Regras de Classificação
- Menos de 10 vitórias → Ferro
- 11 a 20 → Bronze
- 21 a 50 → Prata
- 51 a 80 → Ouro
- 81 a 90 → Diamante
- 91 a 100 → Lendário
- 101+ → Imortal
